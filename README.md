# comfyui-pixel-downscale

**把「高分辨率像素风图」变成真正的低分辨率像素画。**

按颜色分层，每层单独设阈值，再按 z 序叠加 —— 人控制"哪里该保留、哪里该舍"，机器负责剩下的。

> Turn a high-res pixel-art-like image into a true low-res pixel painting.
> Colors are split into layers, each layer gets its own coverage threshold,
> then composited back in a manually-defined z-order.

---

## 为什么需要它

普通缩小（bilinear / nearest）会直接把像素画炸掉。
单纯的颜色量化又控不住细节 —— 你没法告诉它"天空要干净、机翼尖要保留"。

这个节点把控制权拆成三个可以直接调的东西：

| 你控什么 | 怎么控 |
|---|---|
| **哪些颜色留下** | 删掉 layers 里的那一行 |
| **前后关系** | 调行的顺序（越靠下越靠前）|
| **每层要多"厚"才留下** | 改那一行的阈值 |

---

## 安装

把整个 `comfyui-pixel-downscale` 文件夹放进：

```
ComfyUI/custom_nodes/comfyui-pixel-downscale/
```

重启 ComfyUI。节点在 **像素 / 降采样** 分类下。

依赖：只需要 numpy 和 torch（ComfyUI 自带）。

---

## 两个节点

### Pixel Analyze 颜色分析

输入图 → 输出一段「颜色 阈值」文本。

作用是把图里成百上千种颜色（有损压缩产生的相近色）按容差合并成几十种，
让你看清到底有哪几块。

### Pixel Downscale 分层降采样

| 输入 | 说明 |
|---|---|
| `scale` | 1 个大像素 = scale×scale 源像素。192×144 选 4 → 48×36 |
| `layers` | 层列表文本。**留空 = 自动聚类** |
| `tolerance` | 颜色匹配容差（8 ≈ PS 魔棒 8）|
| `default_th` | layers 留空时自动生成的层用这个阈值 |
| `fill` | 没达标的块用覆盖率最高的层填色 |
| `min_neighbors` | 1 = 去掉孤立块 |

| 输出 | 说明 |
|---|---|
| `preview` | 放大回原尺寸，肉眼看效果 |
| `small` | **成品**（低分辨率）|
| `report` | 每层的达标块 / 填充块 / 占比 |

---

## layers 文本格式

```
// 颜色   阈值     —— 越靠下越靠前（z 序）
89CEFF  0.45     // 天空
4D91F4  0.45
4384EE  0.50     // 云层
F4FBFC  0.50     // 云白
4C3D48  0.35     // 机翼深色
EC475B  0.30     // 机翼红尖
```

`//` 后面是注释，颜色带不带 `#` 都行。

## 调参心得

### 1. 先判断哪些颜色是噪点

**不要看颜色深浅，看它的分布**：

- **像素很少，但铺满整张图** → 零散噪点 → 直接删掉那一行
- **像素少，但挤在一个小方块里** → 真细节 → 保留，阈值调到 0.25~0.35

### 2. 阈值按"层的厚度"给

| 层的性质 | 阈值 |
|---|---|
| 大面积实心背景 | 0.55 ~ 0.65 |
| 中等物体 | 0.45 ~ 0.55 |
| 细线 / 尖角 / 小细节 | 0.25 ~ 0.40 |
| 噪点 | **删掉，别靠阈值救** |

噪点随机分布，阈值得拉到 0.9 才接近消失，那时真细节也一起没了。

### 3. 开了 fill 就要把阈值调低

`fill` 是"谁来补洞"，不是"补出对的颜色"。
阈值太高 → 大量块靠 fill → 而 fill 挑的是**覆盖率最高的那层** → 整张图会偏向面积最大的颜色。

**开了 fill，阈值建议 0.35 ~ 0.45。**

---

## 已知限制

- 照片类素材（渐变多）降采样后必然有碎点感，因为它的颜色本来就是连续的。
  这个节点能做的只是把它压成几十块，剩下的"哪块该合并"还得人判断。
- `small` 输出是 RGB，透明区域会被填成黑色。
